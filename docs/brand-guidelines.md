## 2. Logo

- **Isotype**: a stylized "C" arc combined with stacked horizontal bars through a vertical stroke (reads as a blended currency/ledger mark). Ultramarine Blue `#5454FF` only.
- **Wordmark**: `ComeLearnForex` — no space between words, bold weight, custom typeface. The guidelines explicitly state: *"Do not change the logo typography because it's a custom font."* We do not have the font file — never hand-recreate the wordmark in a substitute typeface; use the brand name as plain text elsewhere instead of faking the logo.
- **Lockup**: isotype always appears with the wordmark side-by-side at this ratio; never used alone as a stacked lockup in the shown spec.

### Minimum size
| Context | Minimum |
|---|---|
| Print | 10mm height |
| Digital | 30px height |

### Incorrect usage (explicit "NO" list from the deck)
- No stacked version of the logo
- No wordmark without the isotype
- No rotating the logo
- No colors outside the palette (e.g. no red/pink recolor of the isotype)
- No changing the wordmark weight
- No distorting the logo
- No changing the logotype's typography (custom font)
- No effects applied to the logotype (shadows, glows, etc.)
- No modifying the logotype in any other way

## Notes for design work in this repo

- Prefer Ultramarine Blue `#5454FF` as the single accent color; keep everything else to the black/white/grey neutrals above. Don't invent additional accent hues (e.g. no gold/brass, no green/red trading colors) unless the user asks.
- Never freehand-redraw the isotype or wordmark — use plain text for the brand name until an actual logo asset (SVG/PNG) is provided.
- Typeface is unconfirmed — ask before treating "Poppins" as final, or request the real font name/files.
